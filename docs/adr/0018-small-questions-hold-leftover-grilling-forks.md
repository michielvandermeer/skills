# Small questions tickets hold leftover grilling forks

A wayfinder ticket used to be one fork, so a grilling question that stood alone became its own session. Starting `/wayfinder` for each of those was the cost. A session that kept taking tickets would blow the context window the map exists to protect, so a session still resolves one ticket.

Grilling tickets now come in two shapes. A tree stays Focused. Leftover unblocked one-question forks share one Small questions ticket, even when the subjects differ, with no extra cap beyond the existing 250K session ceiling. New leftovers join that ticket while it is unclaimed. The map's one-line gist lists each decision.

## Considered Options

- Sessions keep taking grilling tickets — rejected: blows the context window.
- Cluster leftovers by subject — rejected: these questions have no shared subject; the point is to get through them fast.
- Cap a Small questions ticket at a handful of questions — rejected: the 250K ceiling is the backstop.
