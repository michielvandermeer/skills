# `/review-spec` uses the session model

A second opinion on a Spec's Solution needs a different model than the one that wrote the Spec. A model name on the command, and a pinned second model on a plugin agent, were both rejected: you already choose the model by opening the session, and a pin names a Claude tier that other hosts cannot honour. `/review-spec` runs in the Driving session. You type it on the host and model you want.
