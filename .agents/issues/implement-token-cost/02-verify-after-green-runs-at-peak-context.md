# Checks after the code is written run at the implementer's largest context

Category: enhancement
Status: needs-grilling
Spec: .agents/specs/implement-agents-start-smaller.md

## Problem

`skills:implementer` runs the per-Step `/code-review`, the fix loop, and the browser pass itself, after its commit is green. By then its context is at its largest. In 48 hours of transcripts (2026-09-24 to 2026-09-26), this work took 29% of implementer spend. Playwright turns averaged 288k tokens of context.

Proposed change: once the implementer's commit is green, a fresh agent does the browser pass, and maybe the review-and-fix loop. It would start at about 35k tokens of context with the diff, instead of 300–400k. Estimated saving: about 7–10% of total spend.

The full measurement is in commit `5d4d45e`, in the Issue this one was split from.
