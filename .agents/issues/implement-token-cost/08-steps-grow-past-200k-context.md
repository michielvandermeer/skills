# Step agents grow past 200k tokens of context

Category: enhancement
Status: needs-grilling

## Problem

Step agents run 100–175 turns and grow to 350–590k tokens of context. In 48 hours of transcripts (2026-09-24 to 2026-09-26), turns above 200k context took 54% of implementer spend.

Proposed change: slice Steps smaller, so each one stays under about 200k context. Smaller Steps also pay for more setup: about 34k tokens per agent, plus the Spec and Outcome reads.

The full measurement is in commit `5d4d45e`, in the Issue this one was split from.
