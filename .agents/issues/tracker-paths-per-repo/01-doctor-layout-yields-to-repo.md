# Decide whether `/doctor`'s layout yields to a repo's own tracker layout

Category: enhancement
Status: needs-grilling

## Problem

`/doctor` moves every document to a place fixed in its own table (`skills/doctor/SKILL.md`, "Canonical locations"). A repo that keeps its documents somewhere else has no way to tell it so.

mvdmio-suite keeps them per app: `.agents/<app>/specs/`, `.agents/<app>/ideas/`, `.agents/<app>/issues/`, `.agents/<app>/prototypes/`. Its `.agents/refs/issue-tracker.md` sets this out. A `/doctor` run there on 2026-10-01 (suite commit `780044e`) had to override the skill's table to build that layout. The suite's retro then added a line to its own ref (`f3fc990`) telling `/doctor` that a document in its app folder is already where it belongs.

`skills/doctor/MULTI-CONTEXT.md` says every document other than an ADR moves "to the one root `.agents/`, because every skill reads only that root". The skills in this repo do read only that root. mvdmio-suite gets around that by telling every skill, in its own ref, to put `<app>/` after `.agents/`.

## Open questions

- Should `/doctor` read a repo's own layout at all? [ADR-0001](../../../docs/adr/0001-fixed-local-issue-tracker.md) says the tracker has no per-repo setup, and that a leftover `issue-tracker.md` is inert.
- If it does, where does that layout come from: a ref file with a fixed name, the `CONTEXT-MAP.md`, or something else?
- Is "one `.agents/` folder per context" a layout the skills should support themselves, so no repo needs to override them? This hangs on [02](02-skills-take-paths-from-repo.md).

## Comments

> *This was generated by AI during triage.*

**Why needs-grilling:** there is more than one way to fix this, and the choice goes against a decision already in force. Someone has to pick one.

**What we know.** The table in `skills/doctor/SKILL.md` has no exception for a repo's own layout. `MULTI-CONTEXT.md` only sends ADRs to a context's own folder. The one place the skills already keep a file per context is the Run recipe (`skills/implement/PROOF.md`): `<context folder>/.agents/refs/run-recipe.md`. mvdmio-suite uses a different shape, `.agents/<app>/`, and has app folders with no `CONTEXT.md` (`shared/`, `statistics/`).

**What is blocked:** any change to `skills/doctor/SKILL.md` and `skills/doctor/MULTI-CONTEXT.md`. Decide this together with [02](02-skills-take-paths-from-repo.md) in one `/grill-with-docs` session, because the answer to 02 decides what `/doctor` has to respect.
