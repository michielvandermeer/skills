# Planner inherits the session's high effort

Category: enhancement
Status: needs-grilling

The `/implement` Planner runs at the Driving session's own model and effort. [ADR-0007](../../../docs/adr/0007-pinned-subagent-model-tiers.md) left it there on purpose: slicing a Spec is treated as judgement, not as Spec-bound dispatch. Step agents are pinned cheaper. The Planner is not.

On fourteen Grok `/implement` runs from 12–13 September 2026, every Planner ran at high effort on grok-4.6 or grok-4.5. Each extra round then cost tens of seconds. On the slow runs, late rounds cost one to three minutes because the window had grown.

Bounding the walk (see `.agents/specs/implement-planner-walk-bound.md`) cuts how many rounds fire. It does not change the cost of each round. Whether the Planner should stay at session effort is a separate decision.
