# File the findings

The filing step both hunts share. Each hunt hands it `findings.md`, one entry per finding. Carry out each Tracker operation as `.agents/refs/tracker.md` says, or as [setup/LOCAL.md](../setup/LOCAL.md) says when the repo has no ref.

1. List the open Issues. A finding an open Issue already covers adds its entry to that Issue as a comment, starting with `> *This was generated by AI during a hunt.*`, and is filed no second time.
2. File every other finding as its own Issue in `needs-triage`, leaving the category to `/triage`. Its title is the finding's title, and its body is the finding's entry without the screenshot images.
3. Attach each filed or commented finding's screenshots to its Issue. When the Tracker ref gives no Attach, says it is unavailable, or an upload fails, comment the image paths instead and name each file in the closing summary for the user to add.
4. Delete the scratch folder. When the summary names screenshots for the user to add by hand, keep the folder and name its path instead.
5. Show a summary: each finding with the reference of the Issue it filed or commented on, and a line telling the user to run `/triage` on the `needs-triage` Issues.

Done: every finding is filed or commented on, its screenshots are attached or named, and the scratch folder is deleted or named.
