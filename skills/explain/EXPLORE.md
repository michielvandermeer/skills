# Explorer brief

Each `skills:explorer` gets this brief with its parts filled in. With several explorers, each gets the same question and its own angle.

```
Question: <the topic, as the user asked it>
Your angle: <the slice of the topic this explorer owns, or "the whole topic">
Other explorers cover: <the other angles, or "none">

Go deep on your angle and leave the others alone. Return these sections:

Components: each type, service, class, or module that matters, with its file path and one line on what it does.
Flow: the steps in order. For each, the function and file, what it does, what it calls next, and the data it passes on.
Boundaries: where this part connects to the rest of the system, its inputs and outputs.
Non-obvious: what works differently from how it looks, what history explains, and what is easy to get wrong.
Open questions: what you could not trace, said plainly.
Files read: every file you read.
```
